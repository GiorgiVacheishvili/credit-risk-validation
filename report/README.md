# Report

| File | What it is |
|---|---|
| validation_report.md | The validation report: a short summary of the data, models, performance, stability, explainability, limitations and recommendations |
| notes.md | The detailed working notes behind the report (findings 1–15), written as the analysis progressed |

Start with validation_report.md for the overview, and use notes.md for the details behind
each decision.
